# Pasos para contribuir
1.	Haz un fork del repositorio.
2.	Crea una rama: `git checkout -b mejora/mi-cambio`
3. Reporta un error o propon una mejora con `issue` en el repositorio.
4.	Guarda tus cambios: `git commit -m "Describe tu cambio"`
5.	Sube la rama: `git push origin mejora/mi-cambio`
6.	Abre un Pull Request explicando que mejoraste.
